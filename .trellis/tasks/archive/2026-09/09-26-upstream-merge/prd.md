# 本地 main 跟进上游最新版（merge 上游 84 提交）

## 状态

**已完成，待归档**（2026-09-26）。

## Goal

把本地二开分支 `main` 跟进到上游最新，使后续开发基于最新官方代码，而不是停在分叉点。

## 背景

- 本地 `main` 曾在分叉点 `6449735a` 上二开 184 提交
- 上游领先 84 提交（最新 `0533435b`）
- **该合并的风险已被 `09-26-trellis-oss-sync` 的导出流程完整预演**：`git merge-tree` 零冲突、测试零新增失败、真机启动无错、上游 163 个非重叠文件逐字节保留

## 方案：merge 而非 rebase

`git merge origin/main`

- 184 个提交 rebase 到 84 个新提交上需要 184 次重放，而本地 `main` **没有推送目标** → rebase 改写历史零收益
- merge 一次到位，保留真实分叉形状
- 完全可回退：本地 `main` 无法推送，出问题 `git reset --hard f1a9a01c` 即原样复原
