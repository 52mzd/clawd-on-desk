# 多项目筛选（v3 #2）

## 范围

独立 Trellis 视图顶部加项目 chip 行：

- 每个 root 一个 chip（label = root basename，重名时显示 `name (parent/parent)` 去歧义）
- 状态：全部（默认，跨项目合并列表）/ 单选某项目
- chip 计数：该项目活跃任务数（归档区同理标注）

## 约束

- 筛选是纯渲染层状态（聚合后过滤），不改数据面
- 单项目模式下标题显示项目名；全部模式显示 "全部项目"
- 空项目（0 活跃 0 归档）chip 置灰但可点（进去看空态）
- 7 语言（"全部项目" 等键）
- 筛选状态不持久化（会话级 UI 状态）

## 验收

- [ ] 多项目任务在 "全部" 下合并且可区分来源；单选只显示该项目
- [ ] 归档区同样受筛选约束
- [ ] npm test 失败集与基线一致
