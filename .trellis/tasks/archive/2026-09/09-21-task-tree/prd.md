# 任务树（v3 #4）

## 范围

独立 Trellis 视图的任务列表升级为树形：

1. **活跃任务树**：parent 嵌套渲染（v1 分组逻辑已在 dashboard-trellis-panel
   的 groupTrellisTasks，迁移到独立视图并保留孤儿平铺语义）
2. **归档任务树**：归档列表同样按 task.json 的 parent 字段嵌套
   （归档任务的 parent 可能也已归档——按任务名跨月匹配）
3. **统一视图**：活跃与归档在同一棵树（归档节点灰色 + 完成日期），或
   分两区但共享嵌套逻辑——取实现更直接者
4. 展开/折叠子树（默认活跃全展开、归档收起）

## 约束

- 树构建纯函数（输入任务数组，输出层级结构），环/孤儿/深嵌套安全
  （沿用 v2 groupTrellisTasks 的 slot reservation + emitted guards 模式）
- 归档跨月 parent 匹配按任务目录名（同月优先，跨月唯一匹配，歧义平铺）
- 渲染用 CSS 缩进 + 连接线（纯样式，不引树组件）
- 7 语言（"展开全部/收起全部" 键）

## 验收

- [ ] 父子任务嵌套显示；点击父任务行展开/折叠子树
- [ ] 归档任务的归档父也能嵌套；歧义/环安全
- [ ] 树构建纯函数单测（含 200 任务规模）
