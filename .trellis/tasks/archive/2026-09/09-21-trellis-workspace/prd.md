# 独立 Trellis 视图（v3 #1 地基）

## 范围

1. **Dashboard 独立 tab**：侧栏/顶部加 "Trellis" 视图入口，与 Sessions 视图
   平级切换。视图内容 = 活跃任务区 + 归档浏览区（从会话面板里搬过来并扩展）
2. **roots 持久化**：`getKnownRoots()` 已是正向缓存（会话结束后保留），
   但进程重启即失。把已知 roots 低频持久化（prefs 或 ~/.clawd 下独立小文件），
   启动时载入
3. **手动管理项目根**：视图内可添加（目录选择器）/ 移除项目根，解决
   "从未有过会话的项目也能看归档"
4. **归档浏览去会话化**：归档列表的数据源从 live-cwd 白名单改为
   "已注册 roots"（持久化 roots + 会话正向缓存），无活跃会话也能列出

## 约束

- 现有会话内嵌 Trellis 面板保留（活跃绑定视角仍有价值），归档浏览移到
  独立视图后会话面板的归档折叠区删除（避免双入口漂移）
- roots 持久化写入频率：仅 roots 集合变化时写；文件格式极简（JSON 数组）
- readArchiveList 信任面扩展：roots 来源从"会话解析过"扩为"持久化注册过"，
  手动添加的 root 必须经用户显式操作（目录 picker），不接受 renderer 传路径
- 7 语言 i18n；无 roots 时空态引导（"添加项目根"按钮）
- 新 IPC 通道补 session-ipc.test.js 白名单 + trusted-frame 门禁

## 验收

- [ ] 无任何活跃会话时打开 Trellis tab：列出持久化 roots 的活跃+归档任务
- [ ] 添加/移除项目根即时生效并持久化（重启后仍在）
- [ ] 会话面板不再有归档折叠区；独立视图功能齐全
- [ ] npm test 失败集与基线一致
